# Конкурентный анализ — A Conscious Life

> Исследование рынка приложений для трекинга состояния, осознанности и личного роста. Март 2026.

---

## TL;DR

Рынок habit/mood-трекеров переполнен (~700+ приложений), но **ни одно не совмещает всё**: таймер активностей + снимки настроения + философский фреймворк (добродетели/архетипы) + паттерны-инсайты в одном продукте. Наш дифференциатор — **смысловой слой**: осознанность через паттерны, а не только данные.

---

## Рынок

- Объём рынка habit-трекеров: **$1.7B (2024)** → **$5.5B (2033)**, CAGR 14.2%
- 63% пользователей, ориентированных на велнес, используют трекер хотя бы раз в неделю
- **52% отказываются от приложения в первые 30 дней** — главная проблема retention
- 44% бросают после первого пропуска стрика — баг в мотивации через guilt

## Основные конкуренты

### 1. Daylio — *ближайший по функциям*

**Суть:** Micro-journaling без текста. Настроение + активности за день, визуальная аналитика.

| Плюсы | Минусы |
|---|---|
| Очень низкий порог входа (30 сек/день) | Нет таймера активностей — только теги |
| «Year in Pixels» — мощная визуализация | Нет философского/смыслового слоя |
| Корреляции настроения и активностей | Нет утреннего/вечернего ритуала |
| Gamification: цели, стрики, достижения | Нет свободной рефлексии |

**Цена:** Free + Premium $35.99/год
**Рейтинг:** 4.8/5
**Наша позиция vs Daylio:** Daylio — инструмент фиксации. Мы — инструмент роста.

---

### 2. Stoic. — *ближайший по философии*

**Суть:** Журнал на базе стоицизма. Утренние намерения + вечерняя рефлексия + CBT-упражнения + аналитика настроения.

| Плюсы | Минусы |
|---|---|
| Та же структура: утро/вечер/рефлексия | **Только iOS** — нет Android |
| 4M+ пользователей, Apple Editors' Choice | Нет трекинга активностей с таймером |
| «Socratic AI» — ИИ-коуч в реальном времени | Нет системы архетипов |
| Voice journaling | Нет снимков состояния в течение дня |
| Экспорт для терапевта | Нет аналитики времени |

**Цена:** Free + Premium $39.99/год
**Рейтинг:** 4.8/5
**Наша позиция vs Stoic:** Stoic — философский журнал. Мы — трекер жизни со смысловым слоем.

### 3. Bearable — *ближайший по аналитике*

**Суть:** Многофакторный трекер здоровья. Настроение, симптомы, сон, питание, лекарства → корреляции в разделе «Impacts».

| Плюсы | Минусы |
|---|---|
| Мощнейшая система корреляций | Позиционирование — хронические болезни, не рост |
| Полная кастомизация всего | Тяжёлый UX, steep learning curve |
| 900K+ пользователей | Нет ритуалов (утро/вечер) |
| Apple Health / Google Fit интеграция | Нет философского/смыслового слоя |
| Клиническое признание (Cedars-Sinai) | Избыточен для «обычного» человека |

**Цена:** Free + Premium $34.99/год
**Рейтинг:** 4.8/5 (iOS), 4.7/5 (Android)
**Наша позиция vs Bearable:** Bearable — медицинский трекер. Мы — для здорового человека, который хочет расти.

### 4. Reflectly — *ближайший по ежедневному ритуалу*

**Суть:** AI-журнал для начинающих. Guided prompts, настроение, мотивационные инсайты.

| Плюсы | Минусы |
|---|---|

| Приятный дизайн | Нет реальных инсайтов из данных |
| | Нет рефлексии с философским контекстом |

**Наша позиция vs Reflectly:** Reflectly — мягкий вход в журналирование. Мы — для более осознанного пользователя.

### 5. Day One — *золотой стандарт журналирования*

**Суть:** Мультимедийный дневник. 15M+ загрузок, Apple App of the Year, фото/видео/аудио + автоконтекст (погода, геолокация).

**Наша позиция vs Day One:** Разные задачи. Day One — память о жизни. Мы — анализ паттернов и рост.

### 6. Finch — *ближайший по эмоциональному вовлечению*

**Суть:** Self-care + геймификация через виртуального питомца. Mental wellness + habit tracking + breathing + bullet journal.

| Плюсы | Минусы |
|---|---|

| Геймификация через «rainbow stones» | Нет глубокой аналитики |
| Низкий порог | Нет философского слоя |

**Наша позиция vs Finch:** Finch — эмоциональная поддержка. Мы — структурный рост через осознанность.

## Тренды рынка 2026

1. **AI everywhere** — Stoic's Socratic AI, Headspace's Ebb, Calm's ML. Без AI-слоя будет всё труднее конкурировать.
2. **Privacy-first** — on-device AI, E2E шифрование. Наше локальное хранение — конкурентное преимущество сейчас, но нужна синхронизация.
3. **Multimodal input** — голос, фото, рукопись. Текст-only уже не норма.
4. **Gamification** — 47% прирост вовлечённости при badge/streak системах.
5. **Wearables** — интеграция с Apple Watch/Wear OS даёт +39% retention.
6. **Терапевтическая интеграция** — врачи и психологи рекомендуют приложения; экспорт данных для специалиста становится must-have.

## Наши дифференциаторы

### Уникально у нас:
- **Архетипы дня** — ни у кого нет автоматической системы Мудрец/Правитель/Герой/Искатель
- **Таймер активностей** (не теги, а настоящее время) — ближайший аналог это RescueTime, но он рабочий, не личный
- **Снимки состояния в течение дня** + вечерняя агрегация — это точнее, чем одна оценка «за день»
- **Ценностный разрыв** (добродетель vs. события) — уникальная психологическая механика

### Сильные стороны, которые стоит развивать:
- **Кроссплатформенность** (web = и iOS, и Android) vs Stoic's iOS-only
- **Реальные инсайты из данных пользователя** (не mock) — приоритет Спринта 3
- **Приватность по умолчанию** (localStorage) — нет облака, нет утечек
