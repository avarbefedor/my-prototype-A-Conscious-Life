# Осознанная жизнь — описание продукта

> Этот файл — живой документ. Claude читает его перед правками и обновляет по мере развития продукта.

## Суть продукта

**Осознанная жизнь** — мобильное приложение для ежедневного трекинга состояния, времени и личного роста.

Идея: жить осознаннее — значит замечать, как ты тратишь время, что влияет на твоё настроение и энергию, и какой версией себя ты проявляешься каждый день.

Приложение предлагает простой ежедневный ритуал:
1. **Утром** — установи намерение на день
2. **Днём** — фиксируй активности и снимки состояния «здесь и сейчас»
3. **Вечером** — подведи итог дня, отрефлексируй через выбранные линзы
4. **Со временем** — смотри паттерны, получай инсайты

## Экраны

### 1. Сейчас (`/`)
Главный экран. Отражает текущий момент дня.

- **Утреннее намерение** — textarea вверху (показывается если активна хоть одна линза). Сохраняется в `DayLog.morningIntent`
- **Стрик** — счётчик подряд заполненных дней (мотивация к привычке)
- **Сетка активностей** — карточки с эмодзи. Нажал — начался таймер. Нажал снова — завершил. Можно перетаскивать, кастомизировать, добавлять свои
- **Снимки состояния** — в любой момент можно зафиксировать настроение (0–10) + энергию (0–10) + комментарий + **триггер** (теги: Работа / Отдых / Общение / Физическое / Событие / Спонтанно)
- **События/теги** — быстрые метки значимых событий: алкоголь, жор, ПА, конфликт, озарение и т.д.
- **Кнопка «Вечерний ритуал»** — переход к итогам дня

### 2. Вечерний ритуал (`/evening`)
Двухшаговый флоу подведения итогов. Открывается вручную.

**Шаг 1 — Обзор дня:**
- Таймлайн активностей (автоматически из дневного трекинга)
- Результаты `detect`-линз (напр. jungian — автоопределённый архетип дня)
- Сон: кол-во часов + качество
- Итоговое настроение и энергия (0–10)
- Работа и тренировка: оценка −/норм/+
- Шаги и калории

**Шаг 2 — Рефлексия:**
- Активные `select`/`rate`-линзы — каждая рендерится через универсальный `LensBlock`:
  - `select` → группа пилюль (выбрать одну)
  - `rate` → список слайдеров по 0–10 на каждый якорь
- Свободный текст: «Почему день был таким?»

### 3. Лента (`/feed`)
История дней в трёх режимах:

- **Неделя** — 7 ячеек с цветом настроения, полосками активностей, иконками событий. Сводка снизу: среднее настроение, сон, шаги, тренировки, топ активностей, **энергобаланс** (заряжающие vs истощающие активности в часах, если слой Energy разблокирован)
- **Месяц** — календарная сетка, цвет ячейки = настроение дня
- **Активности** — donut-диаграмма распределения времени + ранжированный список за день/неделю/месяц

### 4. Инсайты (`/insights`)
Аналитика паттернов за последний месяц.

- Фильтры по слоям: **Все / Базовые / Паттерны / Энергия / Линзы**
- Карточки инсайтов: заголовок + описание + сила корреляции + значок слоя + кол-во наблюдений
- Инсайты из заблокированных слоёв → размытая карточка (`blur`) с оверлеем «🔒 Слой X — Открыть →»
- Баннер с количеством заблокированных инсайтов
- Тап на заблокированную карточку → открывает `PaywallSheet`

### 5. Профиль (`/profile`)
Настройки пользователя.

- **Мои линзы** — список 5 встроенных линз с тоглом активации:
  - Раскрытие → описание якорей, вопрос для вечерней рефлексии
  - `jungian` → donut-диаграмма распределения архетипов по истории дней
  - `act-values` → выбор 3–5 личных ценностей из банка 15 пунктов
- Прочие настройки: активности, события, тема

### 6. Детальный день (`/day/:date`)
Полная карточка конкретного дня: все данные, активности, снимки, рефлексия, значения линз.

## Ключевые концепции

### Система Линз

Линза — универсальная форма психологической интерпретации дня. Пользователь выбирает 1–2 активных линзы; вечерний ритуал и инсайты адаптируются к этому выбору.

**Три типа якорей:**

| Тип | Что делает пользователь | Пример |
|---|---|---|
| `select` | Выбирает одну из N смысловых единиц | Стоические добродетели |
| `rate` | Ставит 0–10 каждому якорю | Ценности ACT, PERMA |
| `detect` | Ничего — система определяет автоматически | Юнгианские архетипы |

**5 встроенных линз:**

| Линза | Тип | Якоря | Цвет |
|---|---|---|---|
| `stoic-virtues` — Стоические добродетели | select | Мудрость, Умеренность, Мужество, Справедливость | #14b8a6 |
| `jungian` — Архетипы | detect | Мудрец, Правитель, Герой, Искатель | #6366f1 |
| `act-values` — Ценности ACT | rate | 3–5 выбранных пользователем ценностей | #10b981 |
| `perma` — PERMA | rate | Позитивные эмоции, Вовлечённость, Отношения, Смысл, Достижения | #f59e0b |
| `mindfulness-quality` — Качество внимания | select | Присутствие, Реакция, Автопилот, Принятие | #8b5cf6 |

### Слои монетизации

Данные одни и те же — интерпретация становится глубже по мере разблокировки слоёв:

| Слой | Цена | Что даёт |
|---|---|---|
| **Базовый** `base` | Бесплатно | Трекинг активностей, настроения, событий. Основные инсайты |
| **Паттерны** `patterns` | Платно | Корреляции: события → настроение, сон → продуктивность, активности → энергия. Движок `computePatterns()` |
| **Энергия** `energy` | Платно | Хронотип, энергобаланс, Recovery Score, пиковые часы. Движок `computeEnergyInsights()` |
| **Линзы** `lenses` | Платно | Аналитика через выбранные смысловые линзы, утреннее намерение |

В прототипе все слои разблокированы (`isLayerUnlocked()` возвращает `true`).

### Активности
14 активностей по умолчанию (Работа, Спорт, Чтение, Соцсети, Общение, Семья, Готовка, Учёба, Хобби, Прогулка, Отдых, Медитация, Дорога, Развлечения). Каждая с эмодзи и цветом. Пользователь может добавлять, удалять, переименовывать, менять эмодзи и переставлять.

Для расчёта **энергобаланса** активности делятся на:
- **Заряжающие**: Спорт, Чтение, Общение, Семья, Хобби, Прогулка, Отдых, Медитация, Готовка
- **Истощающие**: Работа, Соцсети, Дорога

### События/теги
Быстрые метки для значимых событий дня: Алкоголь, Жор, Паническая атака, ПМ, Курение, Конфликт, Хорошая новость, Плохая новость, Озарение, Благодарность. Интенсивность: слабая / обычная / сильная.

### Снимки настроения
Мгновенная фиксация состояния в любой момент дня. Настроение + энергия по шкале 0–10 + опциональный комментарий + **триггер** (причина). Хранятся с временной меткой, визуализируются в деталях дня. Триггер используется движком `computePatterns()` для анализа источников настроения.

## Дизайн и стиль

- **Платформа:** мобильное web-приложение (React 18, Vite, Tailwind CSS 4.x)
- **Компоненты:** shadcn/ui
- **Анимации:** Motion (Framer Motion) — плавные переходы между шагами, появление элементов
- **Тема:** светлая + тёмная (переключается в профиле), акцентный цвет — indigo (#6366f1)
- **Тон интерфейса:** тёплый, поддерживающий, без осуждения. «Можешь пропустить — но рефлексия даёт лучшие инсайты»
- **Данные:** хранятся локально (localStorage через custom pub-sub store)
