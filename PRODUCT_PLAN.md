## 1. Что у нас есть: инвентарь данных

### Ежедневные метрики

| Данные | Формат | Где собирается |
|---|---|---|
| Сон (часы) | 0.5–14 | Вечер |
| Качество сна | 0–10 | Вечер |
| Настроение (итог дня) | 0–10 | Вечер |
| Энергия (итог дня) | 0–10 | Вечер |
| Снимки настроения | время + mood + energy + комментарий | Сейчас (в течение дня) |
| Активности | время начала/конца + комментарий | Сейчас |
| События | тип + интенсивность (1-10) + описание | Сейчас |
| Шаги | число | Вечер |
| Питание | калории + БЖУ | Вечер |
| Качество работы | +/норм/− | Вечер |
| Качество тренировки | +/норм/− | Вечер |
| Добродетель дня | 1 из 4 + заметка | Вечер |
| Архетип | primary + secondary | Вечер (детектируется автоматически) |
| Рефлексия | свободный текст | Вечер |

### Производные (уже есть)
- Стрик (подряд заполненных дней)
- Распределение архетипов (% по дням)
- Топ активностей по времени (неделя/месяц)
- Тренды настроения/энергии

## 2. Как мы можем интерпретировать данные

### 2.1 Причинно-следственные цепочки

Самое ценное — не факты сами по себе, а **паттерны между ними**.

```
Пример цепочек, которые можно обнаружить:

Сон < 6ч → настроение следующего дня −2.3 в среднем
Алкоголь → качество сна −40%, настроение −1.8 на следующий день
Физ. активность → энергия +1.5 в тот же день
Социальные медиа > 2ч → настроение −0.9
Медитация → снимок настроения через 30 мин: +1.2 настроение
```

### 2.2 Психологические паттерны (по категориям)

**Регуляция эмоций**
- Насколько быстро человек восстанавливается после негативных событий
- Какие активности используются как «эмоциональный регулятор» (еда, соцсети, алкоголь vs. медитация, спорт)
- Разброс снимков настроения за день = нестабильность vs. устойчивость

**Самосаботаж vs. самоподдержка**
- События-триггеры самосаботажа (паника, переедание, конфликт) в связке с контекстом
- Какие условия предшествуют срывам (усталость? плохой сон? одиночество?)

**Витальность**
- Шаги + физ. активность + питание = индекс витальности
- Корреляция с настроением, продуктивностью

**Ценностный разрыв**
- Декларирует добродетель «Умеренность», но события = алкоголь + переедание → разрыв
- Это ключевой психологический момент для роста

**Архетипический дрейф**
- Последовательность архетипов за 30 дней — показывает, «куда идёт» человек
- Например: Герой → Правитель = рост; Мудрец → Искатель = поиск/нестабильность

### 2.3 Временны́е паттерны

- Лучшие дни по дню недели (понедельник vs. пятница)
- Утренние vs. вечерние пики энергии (по снимкам)
- Сезонность (можно позже)

## 3. Что можно добавить: новые элементы

### TIER 1 — Высокий приоритет (меняют ценность продукта)

#### 3.1 Утренний ритуал (Morning Intent)
**Суть**: утром человек ставит намерение на день — один фокус-пункт.
**Психология**: intention-setting снижает cognitive load и повышает следование целям (Self-Determination Theory).
**Данные**: намерение + вечерняя оценка «насколько выполнил» (0-10)
**UI**: карточка на главном экране утром, исчезает после заполнения
**Что даёт аналитику**: корреляция «поставил намерение → день лучше?»

#### 3.2 Триггеры снимков настроения
**Суть**: при добавлении снимка настроения — тег «почему?»
Варианты: Работа / Отдых / Общение / Физическое / Спонтанно / Событие
**Психология**: осознанность причинно-следственных связей = основа CBT (когнитивно-поведенческая терапия)
**Что даёт аналитику**: «Общение всегда поднимает тебе настроение на +1.8»

#### 3.3 Индекс дня (Day Score)
**Суть**: один интегральный балл от 0 до 100, который считается автоматически
**Формула** (настраиваемые веса):
```
DayScore =
  сон(30%) + активности_качество(20%) + питание(10%) +
  настроение(25%) + добродетель_соответствие(15%)
```
**Психология**: gamification + progress tracking = motivation booster
**UI**: большое число на экране «Сейчас», цвет меняется с прогрессом дня
**Что даёт аналитику**: единая метрика для сравнения дней / трендов

#### 3.4 Паттерны (Insights 2.0 — реальные, не mock)
**Суть**: настоящие корреляции, считающиеся из данных пользователя
Минимум данных для паттерна: 7 наблюдений
**Формат инсайта**:
```
🧠 Паттерн обнаружен
«В дни с <5 часов сна ты оцениваешь работу на −/норм в 78% случаев»
Основано на 23 днях наблюдений
[Что делать?] → ссылка на конкретный совет
```
**Категории паттернов**:
- Сон → продуктивность
- Физ. активность → настроение/энергия
- События → следующий день
- Добродетель → архетип
- Время в активностях → качество дня

### TIER 2 — Средний приоритет (глубина и вовлечённость)

#### 3.5 Еженедельная рефлексия
**Суть**: в воскресенье вечером — 3 вопроса о неделе
```
1. Что было лучшим моментом недели?
2. Что мешало тебе быть собой?
3. Одна вещь, которую хочу изменить на следующей неделе
```
**Психология**: рефлексия на уровне недели = другой масштаб осознанности
**Данные**: хранится как weekly_reflection отдельно от DayLog
**UI**: пуш-напоминание + отдельный экран в Feed

#### 3.6 Телесный журнал (Body Check-in)
**Суть**: быстрый чекин физических ощущений — отдельно от настроения
Варианты: Бодрый / Вялый / Напряжённый / Расслабленный / Боль / Лёгкость
**Психология**: соматическая осознанность = фундамент психологического здоровья
**UI**: 5 иконок в строчку, мультиселект, добавляется как отдельный снимок
**Что даёт аналитику**: связь тела и психического состояния

#### 3.7 Социальный контекст дня
**Суть**: с кем провёл день (один / с партнёром / с друзьями / с коллегами / с семьёй)
**Психология**: социальные связи — главный предиктор счастья (Harvard Study of Adult Development)
**UI**: иконки-теги в вечернем ритуале, необязательно
**Что даёт аналитику**: «Ты на 1.7 счастливее в дни с близким общением»

#### 3.8 Стрики по конкретным привычкам
**Суть**: отдельный стрик-трекер для 3–5 выбранных пользователем привычек
Например: «Спал 7+ часов», «Занимался спортом», «Не пил алкоголь», «Медитировал»
**Психология**: habit loop (Duhigg) — визуализация стрика создаёт commitment
**UI**: полоска в верхней части NowPage или отдельный блок в Feed
**Данные**: автоматически считается из существующих данных (если настройки заданы)

#### 3.9 Уровень стресса (отдельно от настроения)
**Суть**: настроение ≠ стресс. Человек может быть в хорошем настроении, но перегружен
**Метрика**: 0–10, добавляется опционально в снимок настроения
**Психология**: аллостатическая нагрузка — хронический стресс без осознанности = выгорание
**UI**: дополнительный слайдер в MoodSnapshot-шторке

### TIER 3 — Будущее (после MVP+)

#### 3.10 Периоды / Фазы жизни
**Суть**: пользователь может пометить период («Отпуск», «Дедлайн», «Переезд», «Болезнь»)
Тогда инсайты сегментируются по контексту жизни
**Психология**: контекст радикально меняет интерпретацию данных

#### 3.11 Связи между людьми (Significant Others)
**Суть**: отдельный трекер качества отношений с 3–5 важными людьми
Раз в неделю: «Как ты с [Имя] на этой неделе?» (0–10)
**Психология**: качество отношений — лучший предиктор долголетия и счастья

#### 3.12 Квартальный/Годовой обзор
**Суть**: автоматически генерируемый «Год в цифрах»
Визуализация архетипического пути, главные инсайты, топ добродетелей

#### 3.13 Цели и выравнивание (Goals Alignment)
**Суть**: пользователь ставит 1–3 цели, система считает «% выравнивания» действий с целями
Например: цель «Здоровье» → трекает спорт + питание + сон и показывает индекс
**Привязка к существующему**: Goals в ProfilePage уже есть (чекбоксы) — развить

## 4. Проблемы текущей архитектуры данных

### 4.1 Нет реального персистентного хранилища
Данные живут in-memory, при перезагрузке — сбрасываются.
→ Нужно: localStorage / IndexedDB / backend sync

### 4.2 Insights — заглушки
Все инсайты сейчас mock-данные.
→ Нужно: движок корреляций на реальных данных пользователя

### 4.3 Время активностей не сохраняется строго
`endTime` опциональный — теряем точность.
→ Нужно: при закрытии активности автоматически фиксировать endTime

### 4.4 События без контекста
Событие «Алкоголь» записывается, но мы не знаем — это бокал вина в честь праздника или запой.
Интенсивность есть, но контекст — нет.
→ Уже частично решено описанием; добавить тег «контекст»?

### 4.5 Нет разницы между утром / днём / вечером в дневных метриках
Настроение «итога дня» может не отражать реальность.
→ Снимки настроения частично решают это, но они необязательные.

## 6. UX-принципы, которые стоит сохранять

1. **Минимальное трение** — любое действие должно занимать < 30 сек. Длинные формы = смерть продукта.
2. **Прогрессивное вовлечение** — сначала простое (настроение), потом глубокое (добродетель, архетип). Не перегружать новичка.
3. **Снимки лучше итогов** — человек плохо помнит «общее настроение за день», но хорошо помнит конкретные моменты. Снимки в течение дня точнее.
4. **Видимый прогресс** — стрики, Day Score, архетип — всё это должно быть заметно и ощутимо.
5. **Без осуждения** — данные отображаются нейтрально. Алкоголь — это факт, не грех. Только инсайты показывают последствия.
6. **Ритуализация** — утро/вечер как якорные моменты. Привычка формируется вокруг ритуала, не напоминания.
7. **Эмпауэрмент, не слежка** — данные принадлежат пользователю. Всё для него, не против него.
