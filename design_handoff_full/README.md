# Handoff: «Осознанная жизнь» — приложение для осознанного трекинга

## Overview

«Осознанная жизнь» — мобильное приложение для бережного отслеживания состояний и привычек: настроение, энергия, тренировки, чтение, медитация, сон. Тон — святилище, а не маркетплейс: тёплый кремовый фон, мягкая типографика, минимум визуального шума. В отличие от классических tracker-app тут акцент на **рефлексию и взаимосвязи**, а не на стрики и геймификацию.

В этом пакете — **полная дизайн-сессия**: основное приложение + два углублённых исследования вариантов (детали инсайта и карточка занятия с подтипами).

## About the Design Files

Файлы — **дизайн-референсы в HTML/React** (single-page React+Babel-in-browser прототипы). Это **не production-код**. Задача — **воссоздать эти макеты в существующем стеке проекта** (React Native / Swift / Kotlin / Flutter — что у вас), используя его дизайн-систему, паттерны, навигацию. Если стека нет — выбрать подходящий под платформу и реализовать.

## Fidelity

**High-fidelity.** Точные цвета (hex), типографика (Fraunces + DM Sans + JetBrains Mono), радиусы, отступы, анимации с таймингами. Воспроизводить с пиксельной точностью в рамках компонентной библиотеки продакшена.

## Структура пакета

### 1. `Осознанная жизнь.html` — основной прототип приложения

Полное приложение с табами и экранами:
- **Сейчас** — главный экран с текущим состоянием, кольцом настроения, чекинами
- **Лента** — хронология занятий и записей
- **Инсайты** — обнаруженные паттерны и взаимосвязи
- **Вечер** — рефлексия дня, ритуал засыпания
- **Профиль** — настройки, серии, статистика

**Два режима представления** (переключатель в Tweaks-панели):
- **Sanctuary** (`layoutMode: "sanctuary"`) — спокойная вертикальная лента карточек
- **Bento** (`layoutMode: "bento"`) — плотная сетка разноразмерных тайлов (вдохновлено Я.Go, но приведено к тёплой палитре)

Bento включён на экранах **Сейчас**, **Лента**, **Инсайты**. На **Вечер** и **Профиль** оставлен спокойный стиль — там медитативность важнее ритма.

Дополнительные tweaks: `darkBg` (тёмная тема), `showIntent`, `showScore`.

### 2. `Варианты детали инсайта.html` — что показывать при тапе на инсайт

Когда пользователь тапает «🏋️ Тренировки → настроение» в Инсайтах, открывается экран с разбором. **4 варианта раскрытия:**

- **A · Бенто-разбор** — иллюстрированная hero-обложка, парные KPI-тайлы (+1.5 пункта / 78% сила связи), карточка сравнения «с/без», таймлайн 30 дней с цветовым кодированием, чёрный CTA.
- **B · Лаборатория** — аналитический режим: сегментный контрол (Сравнение / Распределение / Корреляция), бар-чарты, гистограмма, scatter-plot с линией тренда, список сырых наблюдений. Для тех, кто любит данные.
- **C · Журнал** — нарратив. Крупная типографика Fraunces, цитаты из дневника, минимум хрома, тонкие разделители. Не дашборд, а «глава книги о тебе».
- **D · Бенто × Лаборатория (синтез)** — **рекомендуемый**. Объединяет hero-обложку + KPI-тайлы (А) с сегментным контролом и тремя графиками (B) + последние наблюдения. Полный разбор в одном цельном языке.

### 3. `Карточка занятия.html` — занятия с подтипами

Многие занятия не атомарны: **тренировка** имеет 4 типа (с железом, кардио, плавание, йога); **чтение** — одну активную книгу с прогрессом. Карточка должна это раскрывать. **5 вариантов:**

- **A · Inline expand** — карточка раскрывается на месте.
- **B · Bottom sheet** — модальная панель снизу.
- **C · Mini-grid faces** — все подтипы видны сразу на карточке, один тап.
- **D · Quick-resume + ⇆** — большая кнопка «Продолжить [последний тип]» + маленький switcher.
- **E · Stacked deck** — колода карт, листается стрелками или свайпом.

См. README в `design_handoff_activity_card/` (если он включён) или комментарии в HTML.

## Архитектура экранов

### Навигация
Tab bar внизу, 5 табов: Сейчас · Лента · Инсайты · Вечер · Профиль.

### Главный экран «Сейчас»
- Header «Доброе утро / день / вечер, [Имя]»
- Mood ring (большое концентрическое кольцо настроения + энергия) с CTA «Отметить состояние»
- Бенто-блок «Сейчас»: текущая серия, отмечено сегодня, тренировки за неделю
- Активности: тренировка, чтение (с активной книгой), медитация, прогулка
- В конце — вечерний ритуал (чёрный CTA-pill)

### Лента
- Хронология занятий и записей, сгруппированная по дням
- Каждая запись: иконка + название + время + опциональная заметка

### Инсайты
- Карточки «обнаруженных паттернов»: «Тренировки поднимают настроение на +1.5», «Сон <7ч → энергия −2», и т. п.
- Тап → детальный разбор (см. варианты в `Варианты детали инсайта.html`)

### Вечер
- Спокойный экран рефлексии. Тёмный/приглушённый фон.
- Mood/energy checkin, дневник, благодарности

### Профиль
- Серии, общая статистика, настройки

## State management (минимум)

```
// Глобальное состояние
- currentMood, currentEnergy: 1-10
- streak: number
- todayActivities: Activity[]
- recentInsights: Insight[]
- settings: { darkMode, layoutMode: 'sanctuary'|'bento', notifications }

// Activity (с подтипами)
interface Activity {
  id: string;
  type: 'training' | 'reading' | 'meditation' | 'walk' | ...;
  subtypeId?: string;        // для тренировки — weights/cardio/swim/yoga
  duration?: number;          // минут
  durationData?: any;         // для чтения — bookId, fromPage, toPage
  mood_before?: number;
  mood_after?: number;
  timestamp: Date;
  note?: string;
}

// Insight
interface Insight {
  id: string;
  type: 'correlation' | 'trend' | 'pattern';
  title: string;
  emoji: string;
  color: string;
  metrics: { delta, confidence, sampleSize, ... };
  details: {
    compare: ComparisonData;
    distribution: DistributionData;
    correlation: ScatterData;
    observations: Observation[];
  };
}
```

## Следующие шаги для разработчика

1. Изучить все три файла в браузере (структура, цвет, поведение).
2. Согласовать с дизайнером/PM выбор вариантов:
   - Какой режим основной — sanctuary или bento? (рекомендация: bento на трёх экранах, как сейчас)
   - Какой вариант детали инсайта — A/B/C/D? (рекомендация: D)
   - Какой вариант карточки занятия — A/B/C/D/E? (рекомендация зависит от платформы — для iOS B или D; для Android — C или E)
3. Внедрить дизайн-токены в проект (CSS-переменные, theme файл, design system).
4. Реализовать компоненты в стеке проекта: phone frame, bento grid, activity card, mood ring, insight card.
5. Воспроизвести **анимации точно** — они часть UX (chevron rotate, sheet slide, ring progress, mood transitions).
6. Подключить реальные данные через API.

## Заметки

- **Все эмодзи используются как контентные иконки**, а не как декор. В продакшене — заменить на SF Symbols / Material icons / собственные SVG, если по brand-style эмодзи не подходят. Но эмодзи дают приложению тёплый человечный вид, который сложно повторить иконками — рассмотрите оставить.
- **Mood ring** — концентрические круги SVG с stroke-dasharray, цвет интерполируется по mood-шкале. Логика в `Осознанная жизнь.html` (компонент `MoodRing`).
- **Книжные обложки** в карточках чтения — нарисованы CSS gradient + псевдо-страницы. В продакшене — реальные обложки книг (Goodreads API / OpenLibrary).
- **Графики** в `Варианты детали инсайта.html` — статичные; в продакшене нужна реальная charting-библиотека (Recharts / Victory / D3 / SwiftUI Charts).
